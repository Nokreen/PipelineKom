# PipelineKom

CI/CD pipeline с автоматической проверкой качества кода и уведомлениями в Telegram.

 О проекте

PipelineKom - это автоматизированный конвейер для проверки кода и оповещения команды о результатах сборки. При каждом мерже Pull Request в ветку `dev` запускается анализ кода, после чего в Telegram отправляется детальный отчет.

 Возможности

-  Автоматический запуск при мерже PR
-  Анализ качества кода
-  Сохранение отчетов в артефактах
-  Уведомления в Telegram с полной информацией о сборке
-  Система повторных попыток при ошибках отправки
-  Детальное логирование с цветным выводом

 Структура проекта
PipelineKom/

 Как это работает
1.Разработчик создает ветку feature/ticket-XXX от dev

2.Вносит изменения и пушит в GitHub

3.Создает Pull Request в ветку dev

4.PR мержится

5.GitHub Actions запускает pipeline

6.Выполняется анализ кода

7.Сохраняется отчет в артефактах

8.Отправляется уведомление в Telegram
